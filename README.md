# Break Production, Own It

## Run

Requires Node 22 or later. No dependencies, no network, no configuration:

```sh
node main.ts
```

The program reads `MAKEFUN_OUTPUT_DIR` (default `/output`) and writes the entry line to `entry.txt` inside it.
